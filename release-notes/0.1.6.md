**Chips for CXBoards and txt links.** With CXBoards installed, a `cxboards://b/<board id>` link (or its `http://127.0.0.1:4870/b/…` address) appears as a chip with CXBoards' icon and the board's title. With txt installed, a `txt://note/<id>` link appears as a chip with txt's icon and the note's title. Margin reads both without changing anything, and without those apps the links stay ordinary links.

**One shared assistant connection.** The Margin MCP server can now run as a single long-lived process that every assistant session shares: start it with `--http <port>` to serve MCP at `http://127.0.0.1:<port>/mcp`. It listens on this Mac only. Without the flag it works exactly as before. Assistants are also asked to write for the narrow panel: a short header and brief checklist items rather than paragraphs.

This update is signed and notarized for Apple Silicon Macs. Existing users can install it through **Check for Updates…** in Margin's menu.
