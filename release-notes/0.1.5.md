**More room for your notes.** The search field now sits in the top row beside **New note** and **Hide**, and the Margin wordmark is gone, so your notes start about 50 pixels higher. **⌘ F** still jumps to search. In demo mode, the **Demo notebook** banner marks the sample notebook. The buttons that choose where to search, which appear while you type, now line up with the rest of the panel.

You can now turn off automatic update checks in **Preferences → Your workspace → Check for updates automatically**. With it off, Margin makes no network requests on its own, and **Check for Updates…** still works whenever you choose it.

This update is signed and notarized for Apple Silicon Macs. Existing users can install it through **Check for Updates…** in Margin's menu.
