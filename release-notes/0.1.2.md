Paste pictures and screenshots directly into your notes with **⌘ V**. Images appear at the caret, save locally, and remain in place when you reopen the note. Pasting also works in a blank note, supports undo and redo, and keeps images with portable backups and Markdown exports.

Drag notes onto folder tabs to move them into Inbox, another folder, or a nested subfolder. Dropping onto a subfolder row’s **All** tab moves the note into that parent folder. The destination highlights while you drag, and note and folder ordering stays intact.

The wider text caret now returns reliably after composing text with an input method.

This update is signed and notarized for Apple Silicon Macs. Existing users can install it through **Check for Updates…** in Margin’s menu.
